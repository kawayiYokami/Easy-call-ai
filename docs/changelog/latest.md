# 变更日志

## 发布：v0.11.6

- 修复（chat）：撤回/重新生成补齐前端进行中保护，撤回预览改为以后端真实备份记录判断 `apply_patch` 可回滚状态，避免长会话工具历史在 UI 线程同步解析导致卡死、误判和重复触发。
- 功能（sidebar/settings）：新增独立 Web 设置页；设置侧边栏改为 DaisyUI 动态 drawer 布局并补齐 Lucide 图标，浏览器侧边栏支持直接打开设置页，设置窗口支持拖拽缩放。
- 功能（sidebar/network）：Web / VS Code 侧边栏统一复用桌面聊天布局，新增网络访问页、端口配置与远程访问密码；网络访问支持启用开关与自定义密码，关闭后 Web / IDE 桥服务停止，远程地址优先筛选真实局域网网卡并避开常见虚拟网卡。
- 优化（chat/sidebar）：新增会话控制面板，整合工作目录、远程委托状态与相关操作；聊天标题栏右侧阅读/委托入口改为常驻图标按钮，可直接切换和收起侧边栏。
- 修复（chat）：本地文件 Markdown 链接统一改由阅读侧边栏打开，支持 `path:line` 文件引用；普通 Web 侧边栏也走内置阅读栏，不再把本地链接直接交给外部环境。
- 功能（goal）：新增会话绑定 goal 续跑机制与配套系统提示词，任务到点后可启动委托并续跑到完成；补齐中断后的展示和消息形态，并收紧自动续跑触发时机，避免过度误触发。
- 修复（chat/goal）：引导消息打断流式回复时，前端按正式消息时间线合并 history flush、完成事件和后台补消息；过期轮完成不再清掉当前流式缓存，避免旧回复追加到新消息后面。
- 修复（delegate）：委托失败时支持直接查看失败原因；委托并发、控制面板交互与远程委托状态同步一并修正，减少误停、错位和状态不一致。
- 功能（agent）：支持部门多人格选择与固化执行身份；调度启动后会固化执行部门/人格来源，避免多窗口、切换会话或流式恢复时角色回复错挂到助理人格。
- 修复（chat）：本地会话不再错误注入远程 contact 工具 schema 给 LLM；远程联系人会话点击后直接切换当前会话，不再强制打开独立窗口；远程联系人会话输入区收敛为只保留新建任务按钮的精简面板。
- 重构（chat）：删除代码审查报告页面（reports tab），「发起审查」入口统一移至更多菜单；审查结果通过委托/审查面板承载，减少重复入口。
- 功能（codex）：Codex 协议供应商新增 `custom_url` 鉴权模式，自定义 URL 与 API Key 直接并入 Codex 登录卡，专门用于兼容要求 Codex CLI 请求头的第三方中转站。
- 修复（codex）：Codex 供应商改为按三种鉴权模式分别走独立分支；仅 `custom_url` 模式模拟最新 Codex CLI 请求头，官方 `read_local` / `managed_oauth` 模式恢复使用正常 PAI 请求头，不再错误伪装为 Codex CLI。
- 修复（codex）：自定义 URL 模式的运行时解析改为稳定读取 `codexCustomUrl` 与 `codexCustomApiKey`，不再错误回退到官方 URL 或空 API Key；保存链路、脏检查与设置页卡片展示同步修正。
- 修复（chat/runtime）：供应商流式请求重试策略收敛为“仅空回复重试”；429、鉴权失败和其他明确错误不再自动重试，避免错误实现导致无效补发。
- 优化（dev/changelog）：新增 `pnpm changelog:build`，更新日志改为“版本明细为源、脚本生成汇总”；引入 `docs/changelog/releases/*.md`、`docs/changelog/latest.md`、`docs/changelog/remote.md` 和 `docs/changelog/index.json`，应用内远程更新日志同步切换为读取拆分后的轻量文件，避免根 `CHANGELOG.md` 持续膨胀。
- 维护（cargo）：收紧开发测试构建缓存相关配置，减轻本地开发过程中的 Cargo 构建缓存膨胀问题。
