# v0.60.0

## 功能

- 外观新增「自动」主题模式：跟随系统深浅自动切换主题，浅色/深色可分别指定主题（含自定义主题），重启后保持；全新安装默认开启自动模式
- Git 面板上下的「更改」与「提交历史」区域支持折叠/展开，折叠条可整体点击收起，拖拽分界线可调整两区域高度
- Git 面板顶部新增仓库栏：折叠时显示当前仓库名，展开可查看当前目录下发现的所有 Git 仓库并一键切换，更改与历史区同步刷新；打开过的仓库会被记住、下次直接列出，点刷新可发现更深层的仓库
- Git 面板的 diff 视图不再显示 `diff --git`、`index`、`---`/`+++` 等元信息行，hunk 头只保留 `@@ 行号范围 @@`，正文直接从变更内容开始，阅读更干净

## 重构

- 供应商页模型卡改为草稿态编辑：切换思考等级、调整上下文等参数时卡片不再闪跳或拆成多张，保存时才统一拆分
- 简单设置页移除主题切换按钮，主题统一在设置页外观中管理

## 修复

- 供应商页被禁用的思考等级在元数据加载后自动取消勾选，不再出现「勾着但禁用」的状态

## 性能

- 提速首屏加载到 200 毫秒内：启动画面只等待后端就绪与数据迁移等必要步骤，会话、侧边栏等数据改为后台加载，不再阻塞界面
