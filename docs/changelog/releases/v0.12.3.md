# 发布：v0.12.3

- 优化（task）：task 工具 schema 明确要求调度时间、重复频率和结束时间只能写入 trigger，goal/why/todo 只描述单次目标与背景，避免 LLM 把调度语义混入非调度字段。
- 新增（chat）：会话工作目录显示权限等级。
- 修复（chat）：前台快照恢复增加冷却去重，避免恢复前台时重复请求同一会话。
- 修复（chat）：切换会话模型不再广播概览，单会话概览变更改为局部广播。
- 修复（chat）：前端消息读取改为工具结果占位符下发。
- 修复（chat）：截断会话预览文本长度。
- 修复（chat）：修正流式阶段状态显示时序。
- 修复（chat）：放开其他人格消息的撤回入口。
- 修复（remote-im）：修复残留渠道联系人会话复活。
- 修复（ui）：修复会话处理提示主题色。
