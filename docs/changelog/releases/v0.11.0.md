# 发布：v0.11.0

- 功能（chat）：LLM 回复支持标准 Markdown 图片语法 `![说明](路径)` 引用本地图片；聊天内显示缩略图、单击打开 90% 视口原图预览，预览支持复制/保存原图，远程联系人回复按同一语法发送图片并在超大图时压缩。
- 重构（tool-review）：右侧工具审查栏改为统一滚动容器与浮动滚动条，工具评估、代码审查与委托列表分别抽取独立卡片组件；工具评估按文件/终端分组折叠，代码审查与委托按状态分组，委托卡支持头像、进度占位与结果弹窗。
- 优化（chat）：引入 stable render ID 机制，draft 转正式消息时保留渲染 key，避免虚拟列表因 ID 变化触发全量重渲染；新建 `stable-render-id.ts` 工具函数，draft 创建/更新/flush 全链路写入并传递 `_stableRenderId`。
