# 发布：v0.9.82

- 发布（release-0.9.82）：同步前端 `package.json`、Tauri `tauri.conf.json` 与 Rust `Cargo.toml` / `Cargo.lock` 版本号到 `0.9.82`，纳入本轮记忆页筛选/分页交互优化与外观自定义文字强度调节。
- 优化（memory-list-filter-and-pagination-polish）：记忆页新增详细/简要视图切换并记住上次选择；简要模式改为 20 条一页、隐藏理由与标签、正文更紧凑。顶部工作条整合搜索、分页与折叠筛选，支持按人格、6 类画像属性与记忆类型前端过滤；删除记忆时不再强制整页刷新，保留当前分页位置。
- 功能（appearance-text-strength-control）：外观自定义生成主题新增“文字强度”滑条，通过调节 `base-content` 与背景的收敛程度缓解字色过硬问题，同时补齐中英繁文案。
