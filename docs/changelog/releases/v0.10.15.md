# 发布：v0.10.15

- 修复（reload）：LLM 工作区 reload 对不合法的 MCP、Skill、私有人格与私有部门配置改为跳过坏项并继续加载其它合法项；返回 `repairSummary` / `repairItems`，包含文件路径、错误原因与修复建议，便于 LLM 自行修复。兼容旧部门配置缺少 `createdAt` / `updatedAt` / `orderIndex` 的情况，避免配置解析失败卡住新手引导。
- 调整（config）：部门任命改为单选下拉，直接选择当前部门的主执行人格，移除临时的多人格列表式添加界面。
- 修复（chat）：前台会话快照直接返回当前会话的指定模型，前端下拉框改为只读取当前会话头状态，避免切换 A→B→A 后被会话概览覆盖回部门默认。
- 重构（chat-persistence）：会话 metadata 修改收敛到会话服务字段级入口，并增加独立 metadata 内存缓存；指定模型、计划模式、标题、未读数、工作区信息、归档状态、时间戳、当前 Todo、用户画像快照、记忆召回表与会话路由绑定先更新内存缓存再排队落盘；后台持久化支持 meta-only 队列，并在整会话写入时保留字段级 metadata，避免旧快照覆盖用户刚切换的会话模型。
- 功能（chat）：会话增加“指定模型”字段，模型下拉框改为设置当前会话的 `preferredApiConfigId`；调度队列按“会话指定模型 + 部门模型队列”去重生成，并同步覆盖主窗口、独立聊天窗口与 VS Code sidebar。内部 delegate retry 的单次强制模型语义保留，失效的会话指定模型会自动回退部门队列。
