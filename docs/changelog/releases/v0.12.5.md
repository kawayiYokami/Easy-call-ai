- **会话**：禁止老会话自动回填摘要种子（summary_context_seed），避免在加载已存档或历史会话时插入不必要的上下文消息

- **归档**：`summarize_archive_summary_with_fallback` 新增 JSON 无效重试机制（最多3次，每次5秒延迟）；`summarize_compaction_with_model_attempt` 重构空回处理为通用 JSON 无效检测
