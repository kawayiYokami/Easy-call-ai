# v0.74.5

## 功能

- 聊天窗口左下角头像改为下拉菜单，从菜单进入设置或批量归档；顶部不再显示单独设置按钮，界面更简洁
- 输入面板新增「输入面板外观」分组，「IDE 桥文件标签」开关从右键菜单移入此处集中管理
- 流式出字增加淡入动画，并按中文逐字切分，逐字浮现更平滑
- 移动端输入面板改为悬浮卡片交互，并重构分段选择控件
- 委托时间线支持消息回退；新增调度事件系统，委托执行过程与结果更完整地呈现在时间线上
- 自定义委托时会过滤掉自身人格，避免把本人格列为可选项后报错
- 会话轮次执行出错时，错误信息会持久化保存并在各端同步显示，关闭后永久清除
- 聊天中的文件链接支持展开目录树，并可直接回到项目目录
- 文件阅读器新增多文件 diff 可折叠视图，被折叠的内容可展开查看
- Git 面板上中下三栏支持独立折叠，提交区布局优化
- 异步委托相关的 4 条状态文案补齐

## 修复

- 非分段气泡的 markdown 横向内边距调整，贴合气泡自身内边距
- 文件阅读器 Home 键直接以当前会话工作区为准，删除可变锚点消除内容闪烁
- 修复 Git 模式被「工作区跟随」覆盖、以及目录疯狂刷新的问题
- 修复切换会话后侧边栏「是否打开 / 文件-Git」记忆丢失的问题
- 行号列背景改为不透明但保持原色，避免文字透出
- Files/Git 按钮打开状态改为显式高亮
- 右键点击文件头改为折叠全部文件，而非只折叠当前文件

## 性能

- 拖拽文件阅读器侧栏宽度时进行节流，并暂停虚拟列表测量，避免卡顿
