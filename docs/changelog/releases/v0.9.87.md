# 发布：v0.9.87

- 发布（release-0.9.87）：同步前端 `package.json`、Tauri `tauri.conf.json` 与 Rust `Cargo.toml` / `Cargo.lock` 版本号到 `0.9.87`，纳入本轮三栏侧栏交互、界面语言持久化、遗漏 i18n 文案补齐、远程联系人设置本地化与聊天时间分割线等改动。

- 新增（chat-time-divider）：聊天记录在相邻消息间隔超过 10 分钟时自动插入时间分割线，并按当前时间差智能显示“X 分钟前”、时分或日期时间。

- 调整（chat-sidebars-manual-window-expand）：聊天窗口取消按宽高比自动展开会话栏，并移除顶部会话下拉卡片；左右侧栏现在都走手动开关，非最大化/非全屏时打开任一侧栏都会扩宽窗口、关闭后恢复原尺寸，避免聊天正文被侧栏挤窄。

- 修复（ui-language-persist）：界面语言切换改为调用后端专用命令持久化到配置文件，避免只在当前前端会话内生效、重启后回退。

- 修复（i18n-missing-labels）：补齐聊天、日志、API/Codex、更新/审批弹窗与远程联系人设置中的遗漏本地化文案，联系人设置的内置部门名与默认关键词也随界面语言展示。

- 修复（quick-setup-save-errors）：快速设置保存步骤进入统一保存中状态，避免重复点击造成并发保存；配置保存失败会明确显示原始后端错误，配置已写入但运行状态刷新失败时也会返回部分成功语义，且只有召唤热键字段实际变化时才重新注册热键，避免语言/外观等无关步骤被热键占用错误污染。
