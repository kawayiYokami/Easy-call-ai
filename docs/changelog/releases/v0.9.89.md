# 发布：v0.9.89

- 发布（release-0.9.89）：同步前端 `package.json`、Tauri `tauri.conf.json` 与 Rust `Cargo.toml` / `Cargo.lock` 版本号到 `0.9.89`，纳入本轮输入面板模型下拉改为上拉、会话运行状态通知、文件引用阅读器与只读自动刷新、滚动条悬停显示修复。

- 功能（chat-model-selector-upward）：输入面板模型选择器从原生 `<select>` 替换为上拉自定义菜单，选项悬停高亮、选中标记背景色、点击外部自动收起、宽 `w-80` 高 `max-h-80vh`、超长模型名省略、去边框去阴影。

- 功能（chat-conversation-status-notice）：会话列表运行状态新增后台忙碌、未查看完成与失败提示；完成态保留到用户切入会话后清理，后台完成追加消息时即时增加未读数，关闭聊天错误横幅时同步清除对应会话的失败标记。

- 功能（chat-file-reader-context-watch）：聊天右栏文件阅读器新增显式文件片段引用候选，按当前可视范围与用户选区生成可附加上下文，附加后作为快照随消息发送；同时为当前活动文件和可见目录节点加入只读自动刷新，外部变更后自动更新阅读内容与目录节点。

- 修复（chat-markdown-link-style）：修复 Markdown 链接样式。

- 修复（chat-input-floating-scrollbar）：输入框原生滚动条替换为覆盖式浮动滚动条，`resizeChatInput` 中 `minHeight` 从 32 改为 48 对齐 DaisyUI 默认值，无内容时空滚动条不再出现。

## 进行中



- 发布（release-0.9.88）：同步前端 `package.json`、Tauri `tauri.conf.json` 与 Rust `Cargo.toml` / `Cargo.lock` 版本号到 `0.9.88`，纳入本轮更新退出停机、远程 IM 渠道运行态分片、委托打断、聊天三栏标题栏、侧边栏持久化、Markdown 基础样式与滚底定位修复。

- 修复（delegate-abort-and-tool-timeout）：移除工具执行公共层默认 30 秒超时，改为仅工具自身声明超时时才限制；同步委托被外层取消时会级联中止子委托运行态，右侧进行中委托卡片新增“打断”按钮，并记录打断清理失败日志，避免后台委托孤儿任务继续疯狂调用工具。

- 修复（remote-im-channel-state-shards）：个人微信扫码登录态与轮询游标迁移到按渠道分片的后端状态文件，轮询成功不再写入总配置文件；旧配置中的微信 `token/accountId/userId/syncBuf` 会幂等迁移并清理，钉钉、飞书与 OneBot 的用户固定接入参数继续保留在配置层。

- 功能（chat-three-pane-titlebar）：聊天窗口标题栏对齐左中右三栏布局，侧栏开关和本地/远程切换收敛到标题栏区域，并隐藏暂未发布的目录入口，避免未完成文件浏览整合暴露给用户。

- 修复（chat-sidebar-open-state）：左右侧栏打开状态在前端持久化，刷新窗口后按上次布局恢复，避免右侧栏和会话栏每次重启都回到关闭状态。

- 修复（chat-switch-initial-bottom）：优化会话切换首屏定位，统一缓存与非缓存会话的底部初始化路径，避免先闪到第一条消息再跳动。

- 修复（chat-markdown-style）：Markdown 共享样式统一行内代码、表格与代码块容器覆盖；行内代码改为无边框主题底色胶囊，表格按主题色渲染并移除阴影，文件阅读器删除重复覆盖。

- 修复（chat-bottom-reset）：滚到最下按钮复用会话切换的虚拟列表底部初始化路径，避免旧滚动逻辑在弹性空间或测量缓存未稳定时无法真正定位到最新消息。

- 优化（chat-simple-message-padding）：聊天历史无气泡模式下为消息正文恢复左右内边距，避免长文本贴边显示。

- 修复（chat-model-select-opaque）：聊天输入栏模型选择器取消透明 ghost 样式，恢复实底下拉背景，避免模型上拉列表透出聊天内容。

- 修复（windows-updater-before-exit-shutdown）：Windows 安装版自动更新在 updater 硬退出旧进程前先优雅停机远程 IM 与 MCP 后台服务，并保留 Tauri 默认退出清理，避免更新重启后 OneBot 端口和远程联系人运行态残留。
