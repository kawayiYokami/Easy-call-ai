# v0.12.6

## 功能

- **对话**：新增“无要求”对话风格选项，选择后不再注入额外的对话风格提示词
- **网络访问**：新增活动连接清单，前端可查看当前连接数、来源、连接类型与认证状态

## 修复

- **网络访问**：关闭网络访问后，现有 IDE 与 Web 侧边栏连接会立即失效，避免旧连接继续访问
- **网络访问**：固定网络访问端口并缓存链接状态，改进网络访问页状态一致性
- **侧边栏**：限定 VS Code 侧边栏主题覆盖作用域，避免 Web 端标题等元素误用侧边栏前景色，恢复按自身主题显示

## 重构

- **网络访问**：统一本地端口服务生命周期，收敛网络访问服务启动、停止与重启的串行化管理
