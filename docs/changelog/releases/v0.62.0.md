# v0.62.0

## 功能

- Git 面板提交行右键弹出预览卡：可复制提交哈希与提交消息，并支持基于该提交直接新建分支；最新一次提交还可一键撤销（soft，改动保留在暂存区），已推送的提交会提示无法撤销
- Git 面板不再弹出浏览器原生右键菜单，所有右键交互统一走应用内菜单
- 分支列表改为树状展示，本地与远程分支分组可折叠展开；分支删除入口移除，切换按钮移到行尾
- 更改/暂存列表的文件行图标与文件树统一
- 外观默认值调整：气泡与分段默认开启，换行显示默认关闭
