# 发布：v0.10.20

- 修复（chat）：修正会话列表导出与新建会话导入按钮图标方向；代码块标题栏复制按钮改为图标按钮，复制成功时短暂切换为确认图标。
- 优化（chat）：会话列表标题支持单击原地改名，标题区域进入输入态，卡片其它区域继续用于切换会话。
- 优化（chat）：会话列表分组标题改为滚动吸顶，长列表中始终保留当前文件夹入口，便于随时折叠或展开分组。
- 优化（chat）：时间分隔符改为只在历史段加载或会话切换时新增，尾部对话发送、流式与完成替换不再插入新时间条，避免聊天中画面被顶动。
- 修复（chat-stream）：流式 Markdown 分块与 stream block 正文拼接不再 trim 原文空白，保留换行、行首空格和列表标记空格，避免流式态与最终态排版不一致。
- 优化（chat）：无标题会话从首条 10~100 字用户发言开始使用快速模型异步探测 summaryTitle，替代旧的第 5 条消息固定生成策略；已有会话标题或 summaryTitle 时不再重复触发。
- 修复（runtime）：工具调用按批调度，只读工具并发执行、写操作工具串行执行，替换旧的逐个串行逻辑；新增 `PreparedToolCallBatch` 批次抽象与 `runtime_tool_call_requires_serial_execution` 动态判定。
- 修复（reader）：区分侧边目录和浮动目录，文件浏览器面板目录树交互更清晰。
- 修复（chat）：放开手动委托部门选择，用户发起委托时可自由选择目标部门。
- 功能（config）：支持模型角色分工，在设置页可为不同模型配置角色标签。
- 修复（chat）：指令预设点击后直接写入输入框，不再作为文本附件附加。
- 修复（runtime）：统一私域部门运行态视图，自建部门的运行态展示与预设部门一致。
- 文档（skill）：全面更新 pai-guide SKILL.md，修正术语（智能人→智能体）、补充快速设置窗口、新增常用功能板块（目标任务、快捷指令、语音输入、文档附件标记、文档浏览器、委托、代码审查、多选消息转发、会话分支、会话继承、会话导出导入、新建会话、消息队列、引导、@提及、撤回消息、通知、丢弃/压缩/归档、设置、后台日志、托盘）、新增工具与委托执行逻辑说明、工具AI审查原理、会话权限控制。
- 修复（tool-review）：工具评估超时从 12s 硬编码改为 120s，超时后写回可读结论（"快速模型请求超时，劳烦亲自审查"）而非直接报错。
- 修复（tool-review）：补丁预览生成为结构化 diff 格式（`*** Begin Patch` / `-old_string` / `+new_string`），LLM 评估上下文携带 operations 结构化摘要（action/path/old_preview/new_preview/content_preview），不再只给文件名让模型硬猜。
- 重构（tool-review）：输入面板审批卡布局统一为 [查看详情]+摘要 → 评估意见 → [拒绝][批准]；去掉 summaryText 对 message 的 fallback 避免评估意见重复显示；折叠区改用 callPreview（diff 内容）+ 红绿高亮渲染。
- 修复（tool-review）：侧边栏 ToolReviewItemCard 撤回批准/否决按钮（审批只在输入面板），保留折叠详情 + 评估意见 + 查看变更 + 重新评估；超时自动展开详情。
- 修复（ui）：详情弹窗 mockup-code 组件在暗色主题下背景色泛白，改用 base-200 变量覆盖；滚动条样式适配暗色主题。
- 修复（delegate）：用户发起委托不再要求目标部门是直接下级；直接下级校验仅保留在工具调用 delegate 路径；清理 runtime_organization 中废弃的 direct_child_ids_by_parent 快照字段。
