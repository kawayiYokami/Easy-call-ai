# v0.80.0

## 功能

- 时间轴灵动岛全新升级为贪吃蛇棋盘：右下角圆按钮原位展开为毛玻璃卡片，卡片根据消息数量与窗口尺寸自动算出行列与尺寸，点与点以蛇形连线从右下角起按时间倒序来回铺开，单数行靠右、双数行靠左，未填满时不溢出
- 棋盘采用 Git 风格实色点与实色连线，当前位置以空心三角挖孔高亮，悬停的点会放大并变为主色，移动时平滑过渡
- 支持按住滑动预览：手指或鼠标按住卡片后最近的点会实时吸附并更新预览，松开立即跳转，移动端也可流畅滑动操作
- 悬停时在鼠标上方弹出预览卡片，卡片跟随鼠标、靠近边缘自动翻转与钳制，展示用户首行加粗与助理最多四行的正文摘要，字号与正文保持一致，超出按行裁剪
- 滚动到底部工作区工具栏出现时，时间轴按钮与卡片自动让位不再遮挡；卡片展开时底部保留占位，收起动画从圆按钮尺寸顺滑展开与收回
- 预览卡与底盘采用毛玻璃与实色双层设计，底盘半透明、预览卡实色，信息更清晰

## 修复

- 对话气泡左右内边距由 0.82rem 扩大至 1rem，消息内容不再贴边，阅读更舒适

## 性能

- 加载更多历史消息改为按压缩段整块返回，语义为 `[start, anchor)`，可连续翻阅整段历史
- 大块历史一次性渲染导致的卡顿已优化：例如 89 条历史会按 7 条为一片逐帧渲染，每帧约 210ms，滚动与动画保持跟手，语义仍为整块返回
