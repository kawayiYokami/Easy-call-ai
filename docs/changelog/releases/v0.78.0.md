# v0.78.0

## 功能

- 新增商汤科技 SenseNova 生图供应商，切换时自动填入官方网关并预设 U1 Fast 与 U1.5 Lite 两个模型，开箱可用
- 目录选择器升级为标准组件：面包屑与地址栏合一（点击空白切换为输入框）、后退/前进/上一级/刷新四图标导航、Windows 驱动器入口、仅列目录、支持过滤隐藏目录与 .git，空目录自动回退到助理空间，桌面与网页端体验一致；支持列表/网格流式视图切换，卡片铺满窗口 92%，桌面端可一键唤起系统目录选择器，文案完整国际化
- 会话栏切换增加平滑过渡：左侧选中条带主题色竖线与背景阴影过渡，中间消息区以会话为单位淡入淡出，切换更流畅
- 对话区的待办条改为仅在贴近底部时显示，上翻查看历史时自动隐藏不再遮挡，滚回底部时淡入

## 重构

- 工作区卡片视觉收敛：去除多余阴影与毛玻璃，控件统一为中号尺寸，布局更规整
- 全站文案尺寸收敛至标准令牌并打通导出缩放：正文与导出文档跟随界面缩放，阅读尺寸更一致，补偿过小字号的观感
- 修正对话排版的强调与行内代码用法：专有名词与状态名改用加粗，行内代码仅保留给可复制的命令与路径，避免整句被灰底切碎

## 修复

- 修复手机端输入面板在流式回复时出现两个停止按钮、且第二行停止按钮被模型选择器遮挡的问题，发送与停止现为同一位置互斥切换
- 修复生图设置中全部供应商的模型不可手填、不可改名的阻塞问题，现支持直接编辑显示名与接口模型名，预设仅作快捷选择
- 修复直接生成测试无法选择模型的问题，现可在当前供应商的模型中切换测试，不再只能走全局默认
- 修复换目录后上次会话编号串台导致恢复失败的问题：启动时自动比对工作区指纹并回落，切换异常时按未找到清理，不再卡在旧会话
- 修复工作区对话框内分支下拉被对话框遮挡的问题：对话框不再进入顶层，下拉可正常浮于顶层显示
- 修复已用会话的工作树分支被项目当前分支覆盖的问题：目录与工作树模式的分支显示与切换不再串台，切换方向时自动回填或恢复对应分支
- 修复工作树真值显示与分支切换不一致的问题：分支显示永远等于真实 Git 状态，目录模式读项目分支、工作树已创建读工作树当前分支，未创建仅改意图；切换立即生效并完整支持网页端
- 修复草稿中修改主目录后仍操作旧工作树的问题：未保存前分支加载与切换仅作用于新目录，不再对旧工作树执行同步与切换；修复查看计划运行记录时传入对象参数报参数缺失的问题，对象与字符串两种形态均可正常列出
- 修复分支加载失败时静默无反馈的问题：不可用时卡片直接红字提示且控制台同步输出，网页与桌面提示一致
- 修复对话中代码与行内代码字号过小、与正文割裂的问题，现跟随正文 16 体系显示
- 修复表格首尾列贴边缺少左右边距的问题，现恢复均匀内边距

## 性能

- 优化流式 Markdown 渲染：引用与详情块改为增量解析，代码块改为增量着色，流式期间不再整块闪烁或全量重绘，长回复更流畅
