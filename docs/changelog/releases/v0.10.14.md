# 发布：v0.10.14

- 重构（persistence）：会话总索引（花名册）不再落盘为 `chat_index.json`，改为进程内由各会话分片 `meta.json` 派生的内存态；启动时扫描分片重建（含旧 `app_data.json` 回退），运行期随会话增删改做 O(1) 内存更新。移除读路径对账自愈、`include_chat_index` 开关与 `cached_chat_index_mtime`/`cached_chat_index_dirty`/索引修复门等冗余机制，消除索引与会话本体漂移导致的"自愈频繁触发"。
- 修复（persistence）：工具结果直写路径与后台持久化 worker 统一经 `app_data_persist_write_lock` 串行落盘，worker 在写锁临界区内复核 dirty 集合跳过已直写会话，消除写-写竞态与旧快照覆盖（lost update）。
- 修复（persistence）：退出/重启前同步排空待持久化队列，避免 120ms 去抖窗口内的会话/应用数据写入随进程退出丢失。
- 优化（message-store）：原子替换在 Windows 改用 `MoveFileExW`（`MOVEFILE_REPLACE_EXISTING | MOVEFILE_WRITE_THROUGH`）原子替换并写穿透，降低 `rename` 失败回退非原子 `copy` 导致的部分写/文件损坏风险。
- 修复（chat-stream）：自动上下文压缩不再伪装成 `archive` / `organize_context` 工具状态；触发压缩前先用 `round_completed` 关闭当前流式轮并清理后端流式缓存，压缩阶段仅依赖会话 `organizing_context` 运行态，压缩完成后重新开启新调度。
- 优化（prompt）：系统准则新增上下文先行、并行收集与工具调用规模匹配规则，引导助理在需要外部上下文时更快建立事实基础，同时避免简单问题过度搜索。
- 优化（summary-context）：上下文整理摘要改为固定 Markdown 交接格式，查看摘要弹窗使用 Markdown 渲染；用户画像记忆转为列表展示，保留对话在最近完整窗口外继续追加短前缀线索，避免长回复挤掉早期对话脉络。
