## 功能

- 对话消息的 Markdown 排版新增三档布局（紧凑/适中/宽松），可在设置页或会话菜单的外观快捷菜单中切换，切换后聊天气泡的排版密度会实时变化。
- Markdown 排版默认档位调整为适中，新装或未手动调整过布局时默认使用适中排版。
- 分段显示的消息中，段与段之间会显示一条带序号图标的分隔线，方便区分工具调用后的不同正文段落，代码块等内容不会被单独分隔。
- 会话进行中的任务指示条重新设计：顶部展示当前进展与完成进度，展开后可按状态直观看到已完成、进行中和待办的任务列表。
- 会话任务指示条改为云母质感：点击小条会平滑展开成大卡片展示任务进度，悬停可收起，移开自动收起。
- 设置页新增界面字体与代码字体选择：可从系统字体列表中挑选，界面字体应用于对话窗口文字，代码字体用于消息里的代码块，保存后所有窗口即时生效。
- DeepSeek 选择「关闭思维链」后，请求会由模型供应商适配层统一处理关闭逻辑，行为更稳定；文本供应商选项列表改为跟随模型适配层内置清单自动更新，不再手工维护。

## 修复

- 工具调用后的正文在流式显示时会分段换行，但消息完成或打断后却变成一整段不换行，同一内容前后渲染不一致；现在完成态与流式保持同样的分段效果。
- 关闭分段显示后，正文的左右缩进与分段模式不一致，切换开关时排版会跳动；现在两种模式的正文左右间距保持一致，仅分隔线随开关显示或隐藏。
- 会话菜单的二级菜单会错位或飞出屏幕，部分菜单项内容超出卡片边界；现在二级菜单贴合所在一级项展开、始终停留在屏幕内，宽度随内容自适应。

## 性能

- 系统字体列表改为异步加载并在应用内缓存，首次打开后再次进入秒开，不再阻塞界面。
