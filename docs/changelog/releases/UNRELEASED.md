## 功能

- 对话消息的 Markdown 排版新增三档布局（紧凑/适中/宽松），可在设置页或会话菜单的外观快捷菜单中切换，切换后聊天气泡的排版密度会实时变化。三档的标题字号随档位递进：档位越宽松，标题相对正文放大越多；表格仅保留行间横线，去掉了单元格竖线。
- Markdown 排版默认档位调整为适中，新装或未手动调整过布局时默认使用适中排版。
- 分段显示的消息中，段与段之间会显示一条带序号图标的分隔线，方便区分工具调用后的不同正文段落，代码块等内容不会被单独分隔。
- 会话进行中的任务指示条重新设计：顶部展示当前进展与完成进度，展开后可按状态直观看到已完成、进行中和待办的任务列表。
- 会话任务指示条改为云母质感：点击小条会平滑展开成大卡片展示任务进度，悬停可收起，移开自动收起。
- 设置页新增界面字体与代码字体选择：可从系统字体列表中挑选，界面字体应用于对话窗口文字，代码字体用于消息里的代码块，保存后所有窗口即时生效。
- DeepSeek 选择「关闭思维链」后，请求会由模型供应商适配层统一处理关闭逻辑，行为更稳定；文本供应商选项列表改为跟随模型适配层内置清单自动更新，不再手工维护。

## 修复

- 消息中的引用块不再被拆成独立分段，而是留在正文段落内随气泡一起显示；分段只针对代码块（含图表）与表格。
- 撤回消息后，其他同时打开该会话的窗口（如桌面端与 Web 端）会立即同步裁剪被撤回的内容，无需重新进入会话；撤回端本地保持原有即时刷新。
- 另一个窗口撤回的是更早的对话、而当前窗口只加载了会话后段时，现在会自动重新加载权威快照保持一致；之前这种情况下本地会静默跳过同步，导致已撤回的消息仍然残留在界面上。
- 任务指示条在折叠状态时，内部隐藏的收起按钮不再留在 Tab 焦点序列里，纯键盘用户不会把焦点移进看不见的控件；展开/收起状态现在由触发它的按钮对外声明，屏幕阅读器读取更准确。
- 无背景模式下，消息正文各分段之间保留基础段间距，段落不再贴死重叠。
- 三档 Markdown 布局不再改动代码块与行内代码的圆角，圆角统一跟随主题设置；之前切换布局会把代码块圆角改成不同数值。
- 设置页自选的界面字体与代码字体此前保存失败，切换后刷新会还原为默认；现在改动会即时持久化，重启后仍保持所选字体。
- DeepSeek 等带思考开关的模型，现在可以在思考档位里选择「不思考」来关闭思维链；之前这一档被置灰无法点选，导致无法关闭思考。
- 工具调用后的正文在流式显示时会分段换行，但消息完成或打断后却变成一整段不换行，同一内容前后渲染不一致；现在完成态与流式保持同样的分段效果。
- 关闭分段显示后，正文的左右缩进与分段模式不一致，切换开关时排版会跳动；现在两种模式的正文左右间距保持一致，仅分隔线随开关显示或隐藏。
- 会话菜单的二级菜单会错位或飞出屏幕，部分菜单项内容超出卡片边界；现在二级菜单贴合所在一级项展开、始终停留在屏幕内，宽度随内容自适应。
- 代码块中的中文等非英文字符之前会落到系统默认字体，和正文字体观感不一致；现在统一使用界面字体，代码里的英文保持等宽、非英文字符与正文界面一致。

## 性能

- 系统字体列表改为异步加载并在应用内缓存，首次打开后再次进入秒开，不再阻塞界面。
