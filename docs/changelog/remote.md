# 变更日志

## 发布：v0.83.0

## 功能

- 桌面操作能力新增后台操作模式：助手无需切换窗口、不抢焦点，就能直接对指定后台窗口截图、点击（含双击）、填写文本、读取文本、滚动和发送按键——例如地址栏填完网址后直接回车导航，全程不打断你正在做的事。操作结果会报告实际生效的投递方式和操作后焦点落点，界面变化后重复旧操作会得到明确报错而不是错误动作。
- 桌面操作能力增强：助手执行屏幕操作时新增了「移动鼠标」动作，可以把光标移动到指定位置（例如悬停展示提示）而无需点击。

## 修复

- DeepSeek 通过 OpenAI Responses 协议接入时，选择「不思考」现在能真正关闭思维链；此前该选项对 Responses 协议不生效，模型仍会输出思考过程。

## 性能

- 打开含超长思维链或大代码块的消息后，滚动聊天不再周期性卡顿：隐藏弹窗中的原始消息 JSON 与代码全文预览改为打开时才渲染。
- 界面整体响应更流畅：工具评审详情、内置工具目录、远程 IM 日志、运行日志、提示词预览、更新说明、任务编辑、会话维护、批量归档等弹窗关闭后不再在后台保留重内容渲染。

## 发布：v0.82.6

## 修复

- 新建对话的目录下拉不再丢失候选：改为持久化最近使用与侧边栏全量分组两源合并的纯函数，路径大小写与斜杠已归一，每次打开结果一致，切换目录不再让已选目录消失或改名。
- 供应商模型能力同步改为防抖合并：切换供应商不再自动勾选或裁剪思维等级，仅置灰提示需手动重置，保存前会等待在途的模型信息解析完成，避免保存后按钮回弹。
- 文件管理器在目录未改动时不再频繁刷新：监听收敛为当前文件与已展开目录，目录签名已覆盖子项无需对每个可见文件单独轮询，根目录的 Git 内部变动不再计入检测，多窗口按会话隔离各自推送；未展开目录的文件变动不再触发刷新。
- 时间线浮层改为视口锚定：不再被消息区裁剪，监听窗口尺寸、滚动与可视视口实时重算可用区，时间线棋盘在各种窗口尺寸下保持可视。
- 切换目录时页面不再跳动：分支信息区改为常驻占位、不可用时仅置灰禁用；目录下拉选择时不再瞬移到右侧再消失。

## 重构

- 聊天与文件阅读器的虚拟列表统一迁移至 virtua，移除 tanstack 依赖，历史消息加载与文件内容滚动不再闪动，历史补丁与隐藏预量逻辑已清理。
- 设置页改为左右 flex 布局，去除虚化与多余边距，动效收敛；浅色主题字体与对比度、主色层级已重设，界面更清晰。

## 性能

- 文件管理器轮询量由可见行数降至展开目录数，700 毫秒指纹轮询在静止目录下不再触发重载，批量变更仅记录首条差异便于定位抖动源。

## 发布：v0.81.2

## 修复
