# 变更日志

## 发布：v0.77.0

## 功能

- VS Code 侧边栏的「当前项目」在打开工作树目录（`.pai/.worktree/{id}`）时，自动回溯到仓库根并聚合该项目的所有会话
- 对话 Markdown 排版三档（紧凑/适中/宽松）对齐宽松基准的稀疏度，阅读更透气、层级更清晰
- 新建会话与权限选择的工作区卡片重排：目录与分支一行、权限与附加目录一行，控件随卡片宽度自适应伸缩

## 发布：v0.76.1

## 修复

- 修复流式回复末尾正文被吸附到思维链后的乱序问题，回复顺序不再错位
- 修复流式输出时表情与图片不即时渲染的问题
- 修复聊天侧边栏被推开后无法收回、拖拽条点不到的问题

## 发布：v0.76.0

## 功能

- 流式回复改为尾部增量淡入：最后一块内容以 300ms 平滑浮现，代码/表格/数学块直出不参与，60/120Hz 屏幕自适应，系统开启「减少动态效果」时直接显示

## 重构

- 助手消息的正文气泡与头像左缘对齐，不再缩进到头像中线，footer 按钮随之对齐
- 自己发送的消息不再显示头像，气泡直接靠右对齐
- 切换「气泡背景」开关时布局保持不动，只有底色显示或消失
- 关闭气泡背景后，正文分段之间不再显示分割线
- 计划卡在所有模式下都显示为独立气泡块
- 思考与工具面板改为在正文位置展开，与气泡左缘对齐，展开与收起带平滑动画
- 思考与工具列表改为时间线样式，条目节点对齐条目头部并显示类型图标，连线颜色跟随条目类型
- 文件树改为 menu 语义样式，目录折叠交互、展开动画、选中高亮更精致
- Git 树改为 menu 语义样式，提交历史、暂存区、分支列表的折叠与 hover 更精致，长标题自动省略不再把操作按钮推出容器
- 文件与 Git 侧边栏收起/展开以及两者切换时带有平滑的宽度与淡入过渡
- VS Code 侧边栏中从顶栏新建会话时，默认使用 VS Code 当前打开的工作区作为工作目录
- 渠道行为设置重做为统一的标签在上、输入在下的表单布局，4 段分区清晰，移除无功能的冷却字段，内容区与弹窗标题边距对齐且不再出现横向滚动条，能量相关设置平铺展示，仅「什么时候应该回答」保留多行输入

## 修复

- 流式工具徽章不再因模型回复尾随换行而掉行
- 文件阅读器地址栏的目录预览改为点击展开，不再因悬停误触
- 从消息里的文件链接打开文件后，文件夹/Git 栏自动收起，内容区占满阅读区域
- 全项目弹窗统一为原生 `dialog.showModal`，具备 Esc 关闭、点击遮罩关闭与 Top Layer 锁定，视觉与 daisyUI `modal` 动画保持一致（包含「允许 AI 访问的目录」等 30 余处）
- 聊天视图左右分栏的拖拽条改为跟随侧边栏一同显隐，关闭侧边栏时不再捕获鼠标，窗口边缘缩放恢复正常
- 聊天视图宽屏下左右侧边栏以 220ms 推开/收回动画挤开中区，窄屏覆盖模式保持瞬切，拖拽与边缘缩放不受影响
- 标题栏改用原生 `data-tauri-drag-region` 拖动，按钮区双击不再冒泡触发最大化，拖动阈值收紧至 8px，Web 端保留 8px 回退

## 发布：v0.75.0

## 功能

- 思考与工具面板中的思维链改为直接预览：默认显示开头一段内容，超长时点「展开」查看全部、可再「收起」，面板本身仍可整体折叠
- 移除「请求失败时自动切换到下一个模型」：部门设置不再显示该开关，请求失败时直接提示错误，不再静默换用其他模型，避免由此带来的困惑与额外费用
- 设置页移除独立的工具页：助理空间目录移到聊天设置的「执行终端」区块，修改目录时确认是否迁移；内置工具清单移到调试页，在「系统提示词」右侧查看
- codex 供应商的模型管理调整：新增模型从内置候选列表中自行选择，模型名可自由填写，上下文窗口按模型名固定；每个模型默认启用全部思考等级

## 修复

- 修复新增或删除模型时，同一供应商下其他模型的上下文窗口设置被重置为默认值的问题

## 发布：v0.74.6

## 功能

- 「从当前会话创建分支」改为直接复制整个会话快照，无需选择消息，对话生成中也可以创建，且不再出现「无法确定会话分支的消息位置」报错

## 修复

- 恢复聊天窗口标题栏的「设置」按钮：0.74.5 曾将设置入口并入左下角头像菜单，导致顶部设置按钮消失，本次加回，两处入口并存
- 选择消息创建分支不再因压缩占位消息导致中断，分支标题自动退化为不带序号
- 补齐会话分支相关状态提示的缺失文案（简体中文、英语、繁体中文）

## 发布：v0.74.5

## 功能

- 聊天窗口左下角头像改为下拉菜单，从菜单进入设置或批量归档；顶部不再显示单独设置按钮，界面更简洁
- 输入面板新增「输入面板外观」分组，「IDE 桥文件标签」开关从右键菜单移入此处集中管理
- 流式出字增加淡入动画，并按中文逐字切分，逐字浮现更平滑
- 移动端输入面板改为悬浮卡片交互，并重构分段选择控件
- 委托时间线支持消息回退；新增调度事件系统，委托执行过程与结果更完整地呈现在时间线上
- 自定义委托时会过滤掉自身人格，避免把本人格列为可选项后报错
- 会话轮次执行出错时，错误信息会持久化保存并在各端同步显示，关闭后永久清除
- 聊天中的文件链接支持展开目录树，并可直接回到项目目录
- 文件阅读器新增多文件 diff 可折叠视图，被折叠的内容可展开查看
- Git 面板上中下三栏支持独立折叠，提交区布局优化
- 异步委托相关的 4 条状态文案补齐

## 修复

- 非分段气泡的 markdown 横向内边距调整，贴合气泡自身内边距
- 文件阅读器 Home 键直接以当前会话工作区为准，删除可变锚点消除内容闪烁
- 修复 Git 模式被「工作区跟随」覆盖、以及目录疯狂刷新的问题
- 修复切换会话后侧边栏「是否打开 / 文件-Git」记忆丢失的问题
- 行号列背景改为不透明但保持原色，避免文字透出
- Files/Git 按钮打开状态改为显式高亮
- 右键点击文件头改为折叠全部文件，而非只折叠当前文件

## 性能

- 拖拽文件阅读器侧栏宽度时进行节流，并暂停虚拟列表测量，避免卡顿

## 发布：v0.74.2

## 修复

- 修复设置窗口左侧导航栏无法滚动的问题：导航菜单项较多时现在可以正常滚动到末尾

## 发布：v0.74.1

## 修复

- 修复 Web 端与 VS Code 侧边栏的 Git 面板无法使用自动刷新的问题：仓库监听（watch）不再被 Web 端拦截，改动、提交、切换分支等操作会像桌面端一样自动刷新更改区和提交历史

## 发布：v0.74.0

## 功能

- 草稿会话的「和谁对话」卡片新增工作区快捷设置：可以直接切换工作目录（下拉列出侧边栏的所有目录，也能浏览选择任意文件夹），并即时调整权限与工作模式（目录 / 项目内工作树 / 本会话工作树），不用再进设置面板
- Git 面板现在会自动感知仓库的外部变化：在编辑器、终端或其他工具里改文件、提交、切换分支、储藏等操作，更改区和提交历史会及时刷新，不用再手动点刷新
- 部门页的工具开关改为分组开关树：内置工具按用途分类、MCP 工具按服务器归类，可以一键整组开关
- MCP 工具命名统一：服务器返回的工具名自带前缀时保持原样，不再重复加前缀；工具列表不再出现同一工具的两套名字，无描述的重复条目一并消失

## 修复

- 修复 MCP 部署后工具列表空白的问题：探测是异步的，部署完成会轮询等待工具出现再填充列表，不再一直显示「正在探测工具…」或空列表
- 允许不同 MCP 提供同名工具：系统不再拦截或去重，工具可以同名共存，生效顺序由你自己排列

## 发布：v0.73.1

## 修复

- 修复 Web 端（VS Code 侧边栏）无法创建会话的问题：新建会话与草稿打开命令已接入 Web 传输层
- 修复 Web 端迁移完成确认报错、会话创建失败提示显示原始键名的问题

## 发布：v0.73.0

## 功能

- 会话存储全面升级：消息改为多行分组 + zstd 压缩存储，占用更小、读写更快；旧数据在启动后自动后台迁移，实时显示进度与完成汇总，迁移期间界面不再长时间无反馈
- 新建会话改为草稿模式：先选好部门和人格再开口，第一句话发出后草稿自动转正，并随时准备好下一个草稿；对话历史区顶部可以直接修改草稿的部门、人格和模型
- 草稿顶部新增「和谁对话」悬浮卡片：候选按人格聚合展示，选中后回车即可发送转正
- 新建草稿自动带上工作区：文件夹分节新建携带该文件夹路径，标题栏新建携带当前会话工作区，草稿已打开时同样生效
- 追问侧新建改为选择页：可选「在原会话追问」或「在空白会话追问」，支持无上文的空追问
- 「监督任务」更名为「目标」，统一命名并接入追问侧，目标对话框更精简
- 人格头像保存分辨率提升到 256×256，头像更清晰

## 修复

- 修复新建会话偶发失败、创建后新会话从列表消失的问题

## 性能

- 新建会话几乎瞬间完成，不再有可感知的等待
- 日志窗口滚动更流畅，日志量再大也不卡顿

- 供应商页新增模型时，按模型能力自动勾选全部可用思考等级，无需再手动逐档勾选
- 供应商页模型卡默认折叠，仅新增的模型卡默认展开，进入页面更清爽

## 修复
