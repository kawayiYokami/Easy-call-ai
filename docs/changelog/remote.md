# 变更日志

> 此文件由 `pnpm changelog:build` 自动生成，展示最近版本的完整说明。

## 发布：v0.13.8

## 修复

- **配置编辑**：模型卡片的图片/视频能力开关改为使用模型数据库返回的能力字段；数据库未命中时保留人工配置入口，避免按模型名推断导致多模态开关消失
- **多模态模型选择**：多模态分析模型候选改为尊重已保存的 `enableImage` / `enableAudio` / `enableVideo` 能力，不再依赖模型名推断

- **VS Code 侧边栏扩展**：版本同步更新至 0.13.8

## 发布：v0.13.7

## 新增

- **对话输入**：@ 提及智能体时支持按 @ 后输入的内容过滤候选列表，匹配智能体名称或所属部门名称
- **新建会话**：新增 AgentSelector 组件，按部门分组以卡片形式展示人格头像，底部支持模型切换；标题栏与侧边栏新建会话弹窗均已切换为该组件
- **IDE 上下文引用**：新增无行号文件级胶囊，引用整文件时展示更清晰
- **自动记忆注入**：场景提示不再附带 reasoning 文本，减少无关噪音

## 修复

- **聊天消息持久化**：助理消息落盘时不再把 `[toolcall:*]` 展示标记写进正文，避免历史消息出现假的工具图标或不可点击的工具占位
- **撤回**：撤回助理消息时不再错误地把上一条用户消息也撤回；后端放宽撤回目标角色校验，前端「撤回」与「重新生成」拆分处理，助理消息撤回不再映射到上一条用户消息
- **聊天窗口**：从标题栏新建会话时，默认工作目录优先继承当前会话的主工作目录，避免默认选中助理空间
- **聊天窗口**：修正工作目录路径显示与间距，调整打断按钮启用时机，优化发送后自动滚底并规避虚拟列表二次下推
- **工具调用展示**：修正工具折叠条摘要显示，避免工具调用信息误导
- **侧边栏**：对齐发送草稿与滚动行为，避免发送后视图状态不一致
- **代理与工作目录**：修正子代理继承工作目录，并拆分 shell 工作目录与助理空间提示，减少目录语义混淆
- **配置编辑**：新建人格和部门后立即持久化，避免新增后状态未及时落盘

- **VS Code 侧边栏扩展**：版本同步更新至 0.13.7
